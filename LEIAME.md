# Portal Grêmio Desperta ETEC (HTML + CSS + JS, sem banco de dados)
Abra `index.html` ou publique a pasta no Netlify/Vercel/GitHub Pages (arraste a pasta).
## Limitações (sem backend)
- `localStorage` é por navegador: o que o admin cadastra só aparece no navegador dele.
- Para todos verem: no `admin.html` clique em **Exportar seed.js**, substitua `data/seed.js` e republique.
- Propostas e contato **não são enviados**: geram e-mail pronto (mailto) ou texto para copiar. O admin cola a mensagem recebida no painel para moderar.
- O código do admin NÃO é segurança real. Imagens ficam comprimidas no navegador (limite ~5 MB no total; poucas dezenas de fotos).
- Integrantes: foto, idade e rede social só aparecem se autorizados individualmente.
